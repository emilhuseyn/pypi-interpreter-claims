## What the old manuscript missed

1. **Peng et al., ICSE 2024, "Less is More? An Empirical Study on Configuration Issues in Python PyPI
   Ecosystem"** (10.1145/3597503.3639077). PyConf installs releases, picking the interpreter from the
   classifiers; 55,138 releases declare no Python version, 4,155 have declared versions that all fail
   to install (data of November 2022). Read from the arXiv full text.
2. **Li et al., JSS 2025, "Characterizing and detecting Python version incompatibilities caused by
   inconsistent version specifications"** (10.1016/j.jss.2025.112337). PDSpecErr = an incorrectly
   declared Python version range; 3,000 libraries; prevalence, symptoms, diagnostic patterns; PyChecker
   detects and fixes. Read from the abstract only (ScienceDirect and SSRN refused automated access);
   the manuscript says nothing about it beyond the abstract.
3. **Malloy and Power, ESEM 2017 / EMSE 2019**: per-version parsers (PyComply) to measure which Python
   releases applications comply with. The syntax-floor idea is theirs; we use the real parsers.
4. **Vermin** (minimum-version detector, rule table) - now the independent comparison (V2).
5. Neighbours, cited: PyEGo (ICSE 2022), DockerizeMe (ICSE 2019), Yang et al. (IEICE 2024).
   Seen and not cited: knowledge-based runtime inference revisited (TSE 2024), dependency smells in
   Python projects (TSE 2023), PCART (TSE 2024), Python version identification with deep learning.

## Verdict

GO on a narrowed claim, with no "first":
- classifiers and Requires-Python are read as two statements with two audiences, and their disagreement
  is measured (PyConf reads only the classifiers; PyChecker only the range);
- a uniform sample of the index next to the 1,000 most-downloaded projects;
- the declared floor checked statically with eleven real CPython parsers and module tables read from
  the same interpreters, with backports handled, every flagged case adjudicated by hand and the
  instrument compared with ast.parse(feature_version) and with Vermin.

Every cited author list was checked against Crossref and Semantic Scholar (`scripts/30_refs.py`,
16 of 16 agree).
